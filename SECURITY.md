# Security

This repository holds a static, self-contained web page served by GitHub Pages. It has no backend, forms, cookies, analytics or third-party scripts.

- The page sets a strict Content Security Policy. Scripts run only if they match a SHA-256 hash, and the page makes no network requests.

## Reporting a vulnerability

Please report security issues **privately** using GitHub's private vulnerability reporting: go to the **Security** tab and choose **Report a vulnerability**. Please don't open a public issue for a security problem.

Factual errors in the map (dates, stations, status) can be reported as normal public issues.
